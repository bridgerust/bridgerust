# @bridgerust/embex-darwin-x64

This is the **macOS Intel (x64)** binary for `@bridgerust/embex`.

## Installation

This package is an **optional dependency** and should not be installed directly.

Install the main package instead:

```bash
npm install @bridgerust/embex
# or
yarn add @bridgerust/embex
# or
pnpm add @bridgerust/embex
# or
bun add @bridgerust/embex
```
