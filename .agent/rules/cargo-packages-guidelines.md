# Cargo package guidelines and Commenting Policy

Before installing a cargo package always check for the latest version
And check for to see if it's not too old before using it in project. Check if it's compatible with the latest rust version.

Concering the comments.
You should only add the comment if relevant. If the code is self explaining we don't need comments. Always avoid if possible. Put comments it it's really necessary for example for future work, explaining a complex logic you implemented etc.
