## What is a Vector Database ORM?

A **Vector Database ORM** (Object-Relational Mapping) provides a unified interface to interact with various **AI databases** and vector stores. Just as traditional ORMs like Sequelize or TypeORM abstract SQL differences, Embex abstracts the specific API calls of different vector engines.

This is crucial for modern **RAG (Retrieval Augmented Generation)** stacks, where the choice of database might change from local prototyping (LanceDB) to cloud production (Qdrant/Pinecone).

Instead of learning 7 different APIs, you learn **one**:

```python
# Works with ANY provider (Pinecone, Qdrant, LanceDB, etc.)
await client.collection("knowledge_base").insert(documents)
results = await client.collection("knowledge_base").search(query_vector, top_k=5)
```

## Quick Start

<Tabs>
  <TabItem label="Python">
    ```bash
    pip install embex lancedb
    ```

    ```python
    from embex import EmbexClient
    import asyncio

    async def main():
        # Start with LanceDB (Embedded)
        client = await EmbexClient.new_async("lancedb", "./data")

        # Switch to Qdrant later by changing just this line:
        # client = await EmbexClient.new_async("qdrant", "http://localhost:6333")

    asyncio.run(main())
    ```

  </TabItem>
  <TabItem label="Node.js">
    ```bash
    npm install @bridgerust/embex lancedb
    ```

    ```typescript
    import { EmbexClient } from "@bridgerust/embex";

    // Start with LanceDB (Embedded)
    const client = await EmbexClient.newAsync("lancedb", "./data");
    ```

## Supported Vector Databases

Embex supports the most popular vector databases out of the box:

- **LanceDB**: Best for local development and embedded applications.
- **Qdrant**: High-performance, scalable vector engine.
- **Pinecone**: Fully managed, serverless vector database.
- **Chroma**: Open-source, developer-friendly.
- **Milvus**: Built for massive scale.
- **PgVector**: Vector search within PostgreSQL.
- **Weaviate**: AI-native vector database.

## Vector Database ORM vs Raw Clients

| Feature                | Raw SDKs (Pinecone/Qdrant)   | Embex (Vector Database ORM) |
| :--------------------- | :--------------------------- | :-------------------------- |
| **API Consistency**    | Different for every provider | **Unified API**             |
| **Vendor Switch Cost** | High (Rewrite code)          | **Zero (Config change)**    |
| **Performance**        | Varies (often pure Python)   | **High (Rust + SIMD)**      |
| **Local Development**  | Difficult (mocks/docker)     | **Easy (LanceDB embedded)** |
