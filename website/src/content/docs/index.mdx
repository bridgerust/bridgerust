## See It In Action

Write once in Rust. Use everywhere.

<Tabs>
  <TabItem label="Write Once (Rust)">
```rust
    use bridgerust::prelude::*;

    #[bridge]
    struct Calculator {
        value: f64,
    }

    #[bridge_methods]
    impl Calculator {
        #[constructor]
        fn new() -> Self {
            Self { value: 0.0 }
        }

        #[method]
        fn add(&mut self, x: f64) {
            self.value += x;
        }

        #[method]
        fn get_value(&self) -> f64 {
            self.value
        }
    }

````
  </TabItem>

  <TabItem label="Use in Python">
```python
    from calculator import Calculator

    calc = Calculator()
    calc.add(10.5)
    calc.add(5.3)
    print(calc.get_value())  # 15.8

    # 50x faster than pure Python! ⚡
````

  </TabItem>
  
  <TabItem label="3️⃣ Use in Node.js">
```typescript
    import { Calculator } from 'calculator';
    
    const calc = new Calculator();
    calc.add(10.5);
    calc.add(5.3);
    console.log(calc.getValue());  // 15.8
    
    # 10x faster than pure JavaScript! 🚀
```
  </TabItem>
</Tabs>

## The Framework for Universal Bindings

**BridgeRust** unifies `PyO3` and `napi-rs` into a single, zero-cost macro system. Write your logic once in Rust, and deploy native high-performance bindings to Python, Node.js, and beyond.

## Get Started in 5 Minutes

<Tabs>
  <TabItem label="Install (30 sec)">
    ```bash
    # Install the BridgeRust CLI
    cargo install bridge
    
    # Verify installation
    bridge --version
    # bridge 0.1.2
    ```

  </TabItem>

<TabItem label="Create (1 min)">
  ```bash
  # Create a new BridgeRust project
  bridge new my-fast-lib
  cd my-fast-lib
  
  # Start the development server (Live Reload)
  bridge dev
  # Watching for changes...
  ```

</TabItem>

<TabItem label="Build & Docs (2 min)">
  ```bash
  # Build bindings for both Python & Node.js
  bridge build --all
  
  # Generate documentation automatically
  bridge docs --open
  ```

</TabItem>

  <TabItem label="Test & Benchmark (1 min)">
    ```bash
    # Run tests
    cargo test
    
    # Run benchmarks across languages
    bridge benchmark
    # Running benchmarks...
    # Rust: 100ns/iter
    # Python: 5000ns/iter (50x slower)
    ```

  </TabItem>
</Tabs>

## Why Developers Choose BridgeRust

<CardGrid>
  <Card title="Write Once" icon="pencil">
    **DRY (Don't Repeat Yourself).** Define with `#[bridge]` or `#[bridge_module]`. We generate PyO3 and NAPI-RS bindings automatically.
    
    ```rust
      #[bridge_module]
      mod my_lib { 
          pub fn process() {} // Automatically bridged!
      }
    ```
    
    No duplicate FFI code. No maintenance burden.
  </Card>
  
  <Card title="Native Speed" icon="rocket">
    **10-50x faster** than pure Python/Node. Zero runtime overhead. Compiled to native machine code.
    
    Real benchmarks from Embex:
    - Vector search: 50x faster
    - Memory usage: 10x less
  </Card>
  
  <Card title="Type Safety" icon="approve-check-circle">
    **Compile-time guarantees** across language boundaries. Automatic type mapping: `Vec<T>` → `List[T]` / `T[]`.
    
    Catch errors at compile time:
    ```rust
        #[method]
        fn process(&self, data: Vec<f64>) 
            -> Result<String>
    ```

  </Card>
  
  <Card title="Open Source" icon="star">
    **MIT licensed.** Free forever. Built on battle-tested PyO3 and NAPI-RS.
    
    Growing community of contributors.
  </Card>
</CardGrid>
