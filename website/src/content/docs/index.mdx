## Powered by the BridgeRust Framework

Our libraries are built on **BridgeRust**, a framework that unifies `PyO3` and `napi-rs` into a single, zero-cost macro system.

<Tabs>
  <TabItem label="The BridgeRust Way">
    ```rust
    // lib.rs - ONE file for both ecosystems
    #[bridgerust::export]
    fn greet(name: String) -> String {
        format!("Hello, {}!", name)
    }
    // Automagically compiles to:
    // - Python: Native C-Extension module
    // - Node.js: Native .node binary
    ```
  </TabItem>
  <TabItem label="The Hard Way">
    ```rust
    // ❌ Requires duplicate wrappers

    // python_bindings.rs
    #[pyfunction]
    fn greet_py(name: String) -> String { ... }

    // node_bindings.rs
    #[napi]
    fn greet_node(name: String) -> String { ... }
    ```

  </TabItem>
</Tabs>
