BridgeTime ships as native Python and Node.js packages backed by a shared Rust core.

## Install Packages

<Tabs>
  <TabItem label="Python">
    ```bash
    pip install bridgetime
    ```
  </TabItem>
  <TabItem label="Node.js">
    ```bash
    npm install @bridgerust/bridgetime
    ```
  </TabItem>
</Tabs>

## Runtime Requirements

| Target | Minimum | Notes |
| --- | --- | --- |
| Python | 3.9+ | Wheels published through PyPI |
| Node.js | 18+ | Tested on Node 20 LTS |
| OS | macOS, Linux, Windows | Prebuilt binaries by platform/arch |

## Validate Installation

<Tabs>
  <TabItem label="Python">
    ```python
    from bridgetime import bridge_time
    print(bridge_time.now("UTC").format("YYYY-MM-DD HH:mm:ss"))
    ```
  </TabItem>
  <TabItem label="Node.js">
    ```ts
    import { bridgeTime } from "@bridgerust/bridgetime";
    console.log(bridgeTime.now("UTC").format("YYYY-MM-DD HH:mm:ss"));
    ```
  </TabItem>
</Tabs>
