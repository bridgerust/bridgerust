## The Problem

Every vector database has a different API. Switching providers means **rewriting your entire codebase**.

<Tabs>
  <TabItem label="Pinecone">
    ```python
    index.upsert(vectors=[(id, values, metadata)])
    results = index.query(vector=query, top_k=5)
    ```
  </TabItem>
  <TabItem label="Qdrant">
    ```python
    client.upsert(collection_name=name, points=points)
    results = client.search(collection_name=name, query_vector=query, limit=5)
    ```
  </TabItem>
  <TabItem label="Weaviate">
    ```python
    client.data_object.create(data_object, class_name)
    results = client.query.get(class_name).with_near_vector(query).do()
    ```
  </TabItem>
</Tabs>

## The Solution

One unified API. Switch by changing **one line**.

```python
# Works with ANY provider — same code everywhere
await client.collection("products").insert(vectors)
results = await client.collection("products").search(vector=query, top_k=5)
```

```diff
- client = await EmbexClient.new_async(provider="lancedb", url="./data")
+ client = await EmbexClient.new_async(provider="qdrant", url="http://localhost:6333")
```

## Get Started in 60 Seconds

<Tabs>
  <TabItem label="Python">
    ```bash
    pip install embex lancedb
    ```
    ```python
    import asyncio
    from embex import EmbexClient, Point

    async def main():
        client = await EmbexClient.new_async("lancedb", "./data")
        collection = client.collection("documents")
        await collection.create(dimension=768, distance="cosine")
        await collection.insert([
            Point(id="1", vector=[0.1] * 768, metadata={"text": "Hello World"})
        ])
        results = await collection.search(vector=[0.1] * 768, top_k=5)
        print(results.results)

    asyncio.run(main())
    ```
  </TabItem>
  <TabItem label="Node.js">
    ```bash
    npm install @bridgerust/embex lancedb
    ```
    ```typescript
    import { EmbexClient } from "@bridgerust/embex";

    const client = await EmbexClient.newAsync("lancedb", "./data");
    const collection = client.collection("documents");
    await collection.create(768, "cosine");
    await collection.insert([
      { id: "1", vector: Array(768).fill(0.1), metadata: { text: "Hello World" } },
    ]);
    const results = await collection.search(Array(768).fill(0.1), 5);
    console.log(results.results);
    ```
  </TabItem>
</Tabs>

## Supported Providers

<CardGrid>
  <Card title="LanceDB" icon="seti:db">
    **Embedded — zero setup.** Best for local development and prototyping. No Docker, no server.
    ```bash
    pip install embex lancedb
    ```
  </Card>
  <Card title="Qdrant" icon="seti:db">
    **High-performance vector engine.** Best for production workloads. 4.3x faster inserts vs native client.
  </Card>
  <Card title="Pinecone" icon="seti:db">
    **Fully managed serverless.** Best when you want zero infrastructure overhead.
  </Card>
  <Card title="Chroma" icon="seti:db">
    **AI-native embedding database.** Open-source, easy to self-host.
  </Card>
  <Card title="PgVector" icon="seti:db">
    **PostgreSQL extension.** Best when you already run Postgres — no new infrastructure.
  </Card>
  <Card title="Milvus" icon="seti:db">
    **Billion-scale distributed.** Best for massive production deployments.
  </Card>
  <Card title="Weaviate" icon="seti:db">
    **Modular cloud-native.** Best for multi-modal search use cases.
  </Card>
