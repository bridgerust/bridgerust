Embex supports a wide range of vector databases. Switching providers is as simple as changing the provider and URL parameters.

## The Recommended Path

| Stage           | Provider                       | Why?                                                                   |
| :-------------- | :----------------------------- | :--------------------------------------------------------------------- |
| **Development** | **LanceDB**                    | **Zero Setup**. Runs locally (embedded). No Docker or API keys needed. |
| **Production**  | **Qdrant / Pinecone / Milvus** | **Scale**. Managed services, high throughput, distributed.             |

---

## LanceDB (Recommended for Dev)

**Start here.** LanceDB runs in-process and stores data in the local filesystem.

<Tabs>
  <TabItem label="Python">

    ```python
    # Persist to local folder (creates ./data directory)
    client = await EmbexClient.new_async(provider="lancedb", url="./data")
    ```

  </TabItem>
  <TabItem label="Node.js">

    ```typescript
    // Persist to local folder (creates ./data directory)
    const client = await EmbexClient.newAsync("lancedb", "./data");
    ```

  </TabItem>
</Tabs>

## Cloud Providers (Production)

When you're ready to scale, switch to a cloud provider.

### Pinecone

Managed serverless vector database.

<Tabs>
  <TabItem label="Python">

    ```python
    client = await EmbexClient.new_async(
        provider="pinecone",
        url="https://index-name.svc.pinecone.io",
        api_key="your-api-key"
    )
    ```

  </TabItem>
  <TabItem label="Node.js">

    ```typescript
    const client = await EmbexClient.newAsync(
      "pinecone",
      "https://index-name.svc.pinecone.io",
      "your-api-key"
    );
    ```

  </TabItem>
</Tabs>

### Qdrant

High-performance Rust vector database (Cloud or Self-Hosted).

<Tabs>
  <TabItem label="Python">

    ```python
    # Qdrant Cloud
    client = await EmbexClient.new_async(
        provider="qdrant",
        url="https://xyz-example.eu-central.aws.cloud.qdrant.io:6333",
        api_key="your-api-key"
    )

    # Local Docker
    client = await EmbexClient.new_async(
        provider="qdrant",
        url="http://localhost:6333"
    )
    ```

  </TabItem>
  <TabItem label="Node.js">

    ```typescript
    // Qdrant Cloud
    const client = await EmbexClient.newAsync(
      "qdrant",
      "https://xyz-example.eu-central.aws.cloud.qdrant.io:6333",
      "your-api-key"
    );

    // Local Docker
    const client = await EmbexClient.newAsync("qdrant", "http://localhost:6333");
    ```

  </TabItem>
</Tabs>

## Supported Providers

| Provider     | Provider String | Example URL                                  |
| :----------- | :-------------- | :------------------------------------------- |
| **Pinecone** | `"pinecone"`    | `"https://index-name.svc.pinecone.io"`       |
| **Qdrant**   | `"qdrant"`      | `"http://localhost:6333"`                    |
| **Milvus**   | `"milvus"`      | `"http://localhost:19530"`                   |
| **Weaviate** | `"weaviate"`    | `"http://localhost:8080"`                    |
| **Chroma**   | `"chroma"`      | `"http://localhost:8000"`                    |
| **PgVector** | `"pgvector"`    | `"postgresql://user:pass@localhost:5432/db"` |
| **LanceDB**  | `"lancedb"`     | `"./data"`                                   |
