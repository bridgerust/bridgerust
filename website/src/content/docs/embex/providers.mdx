Embex supports a wide range of vector databases. Switching providers is as simple as changing the connection string.

## The Recommended Path

| Stage           | Provider                       | Why?                                                                   |
| :-------------- | :----------------------------- | :--------------------------------------------------------------------- |
| **Development** | **LanceDB**                    | **Zero Setup**. Runs locally (embedded). No Docker or API keys needed. |
| **Production**  | **Qdrant / Pinecone / Milvus** | **Scale**. Managed services, high throughput, distributed.             |

---

## LanceDB (Recommended for Dev)

**Start here.** LanceDB runs in-process and stores data in the local filesystem.

<Tabs>
  <TabItem label="Python">

    ```python
    # Persist to local folder (creates ./data directory)
    client = await EmbexClient.new_async("lancedb://./data")
    ```

  </TabItem>
  <TabItem label="Node.js">

    ```typescript
    # Persist to local folder (creates ./data directory)
    const client = await EmbexClient.newAsync("lancedb://./data");
    ```

  </TabItem>
</Tabs>

## Cloud Providers (Production)

When you're ready to scale, switch to a cloud provider.

### Pinecone

Managed serverless vector database.

<Tabs>
  <TabItem label="Python">

    ```python
    # Option 1: Connection String
    client = await EmbexClient.new_async("pinecone://api-key@environment")

    # Option 2: Explicit Config
    client = await EmbexClient.new_async(
        provider="pinecone",
        url="https://index-name.svc.pinecone.io",
        api_key="your-api-key"
    )
    ```

  </TabItem>
  <TabItem label="Node.js">

    ```typescript
    // Option 1: Connection String
    const client = await EmbexClient.newAsync("pinecone://api-key@environment");

    // Option 2: Explicit Config
    const client = await EmbexClient.newAsync({
      provider: "pinecone",
      url: "https://index-name.svc.pinecone.io",
      apiKey: "your-api-key",
    });
    ```

  </TabItem>
</Tabs>

### Qdrant

High-performance Rust vector database (Cloud or Self-Hosted).

<Tabs>
  <TabItem label="Python">

    ```python
    # Qdrant Cloud
    client = await EmbexClient.new_async(
        provider="qdrant",
        url="https://xyz-example.eu-central.aws.cloud.qdrant.io:6333",
        api_key="your-api-key"
    )

    # Local Docker
    client = await EmbexClient.new_async("qdrant://localhost:6334")
    ```

  </TabItem>
  <TabItem label="Node.js">

    ```typescript
    // Qdrant Cloud
    const client = await EmbexClient.newAsync({
      provider: "qdrant",
      url: "https://xyz-example.eu-central.aws.cloud.qdrant.io:6333",
      apiKey: "your-api-key",
    });

    // Local Docker
    const client = await EmbexClient.newAsync("qdrant://localhost:6334");
    ```

  </TabItem>
</Tabs>
