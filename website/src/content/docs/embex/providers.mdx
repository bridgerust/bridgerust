Embex supports a wide range of vector databases. Switching providers is as simple as changing the connection string.

## Supported Providers

| Provider     | Connection String Prefix | Example URI                              |
| :----------- | :----------------------- | :--------------------------------------- |
| **Pinecone** | `pinecone://`            | `pinecone://api-key@environment`         |
| **Qdrant**   | `qdrant://`              | `qdrant://localhost:6334`                |
| **Milvus**   | `milvus://`              | `milvus://localhost:19530`               |
| **Weaviate** | `weaviate://`            | `weaviate://localhost:8080`              |
| **Chroma**   | `chroma://`              | `chroma://localhost:8000`                |
| **LanceDB**  | `lancedb://`             | `lancedb://./data`                       |
| **PgVector** | `postgres://`            | `postgres://user:pass@localhost:5432/db` |

## Pinecone

Pinecone is a managed cloud-native vector database.

### Cloud Configuration

<Tabs>
  <TabItem label="Python">

    ```python
    # Option 1: Explicit Configuration
    client = await EmbexClient.new_async(
        provider="pinecone",
        url="https://index-name.svc.pinecone.io",
        api_key="your-api-key"
    )

    # Option 2: Connection String
    # pinecone://<api_key>@<environment>
    client = await EmbexClient.new_async("pinecone://abc-123-key@us-west1-gcp")
    ```

  </TabItem>
  <TabItem label="Node.js">

    ```typescript
    // Option 1: Explicit Configuration
    const client = await EmbexClient.newAsync({
      provider: "pinecone",
      url: "https://index-name.svc.pinecone.io",
      apiKey: "your-api-key",
    });

    // Option 2: Connection String
    const client = await EmbexClient.newAsync("pinecone://abc-123-key@us-west1-gcp");
    ```

  </TabItem>
</Tabs>

## LanceDB

### Embedded (Recommended for Local Dev)

LanceDB runs in-process and stores data in the local filesystem. No server required.

<Tabs>
  <TabItem label="Python">

    ```python
    # Persist to local folder
    client = await EmbexClient.new_async("lancedb://./my_db_folder")

    # In-memory only
    client = await EmbexClient.new_async("lancedb://memory")
    ```

  </TabItem>
  <TabItem label="Node.js">

    ```typescript
    // Persist to local folder
    const client = await EmbexClient.newAsync("lancedb://./my_db_folder");

    // In-memory only (Not supported yet in Node bindings)
    ```

  </TabItem>
</Tabs>
